# Очеловечивание текста перед вставкой (T-007, 13.11.2026)

## Суть
- Переключатель «Очеловечить текст» (окно настроек → «Вставка», `paste.humanize`, по умолчанию выключен).
  Включён → перед вставкой и при копировании из истории трея знаки, которых нет на клавиатуре, → клавиатурные.
- Код — `src/humanize.rs` (таблица в `fix`), вызов — `Controller::outgoing` в `src/controller.rs`.
  История диктовок хранит исходник: переключатель действует и на уже распознанное.
- В лог — только «очеловечено знаков: N», текст не пишется.

## Что меняется
| Знак | Замена | Почему |
|---|---|---|
| — ― ⸺ ⸻ | `-`; вплотную к слову/кавычке — ` - `; между цифрами (`1941—1945`) — `-` без пробелов | главный признак текста LLM [S1–S3, S7, S8]; Whisper с русским промптом ставит его тоже [S13, S14] |
| – ‒ − ‐ ‑ | `-` (пробелы как были) | диапазоны, минус в температурах, автозамена Word ` - ` → ` – ` [S12] |
| « » “ ” „ ‟ ″ | `"` | ёлочки на русском — «признак ИИ», люди ставят прямые [S7]; на ЙЦУКЕН есть только `"` [S9] |
| ‘ ’ ‚ ‛ ‹ › ′ ʼ | `'` | апостроф `don’t` [S1] |
| … | `...` | на раскладке нет [S9] |
| NBSP, U+202F, U+2000–200A, U+205F, U+3000 | пробел (не удалять — слова склеятся) | GPT-5 и o3/o4-mini ставят U+202F вместо пробела [S5, S6] |
| U+2028, U+2029 | перенос строки | — |
| U+200B, U+2060–2064, U+FEFF, U+00AD, U+180E, метки направления (U+200E/F, U+061C, U+202A–E, U+2066–9) | убрать | невидимые; так же делает unspook [S16] |

## Что не трогаем и почему
- ZWJ/ZWNJ (U+200D/200C), селекторы вариантов (U+FE0E/F), тег-символы (U+E0000–E007F): из них собраны эмодзи 👨‍👩‍👧, ❤️, флаги 🏴; ZWNJ нужен персидскому.
- № и ₽ — есть на русской раскладке [S9]; ×, ≈, ≤, ≥, ±, °, ² — смысл, который человек продиктовал.
- Стрелки → и маркеры • — модель распознавания ставит их, только если продиктовать «стрелка»; оставлены.
- NFKC вместо таблицы не годится: № → `No`, ½ → `1⁄2`, тире и кавычки не трогает.

## Не проверено
- Как часто `openai/gpt-transcribe` и ChatGPT-транскрипция ставят эти знаки: в истории Handy владельца 5 диктовок
  (377 знаков) — ни одного; выборка мала.
- Telegram Desktop и Word сами превращают `--` в `—` и `<<` в `«` [S11, S12] — там знак может вернуться после вставки
  только если человек допечатывает руками; вставку автозамена не трогает [гипотеза].
